# Quobot — Today Trader market analysis bot

A market analysis bot for the assets you trade on Quotex (forex pairs, gold, indices, crypto).
It pulls public price data, runs common technical indicators and prints a CALL / PUT / WAIT
bias for each asset, with the reasons behind it. It can watch the market and send Telegram
alerts, and it can backtest its own signals so you can see whether they would have made money.

> **Not financial advice.** The bot reads indicators on public market data; it does not predict
> the future. Binary options are high risk and most traders lose money. Never trade money you
> can't afford to lose.

## What it does not do

- **It does not place trades on Quotex.** Quotex has no public API, and automating its site would
  break its terms. You make every trade yourself.
- **It can't analyse Quotex OTC assets** (the ones marked "OTC", mostly at weekends). Those prices
  are generated by the broker and aren't on any public feed. Use the regular market pairs.
- Prices come from Yahoo Finance (forex, metals, indices) and Binance (crypto). Quotex's quotes can
  differ slightly from these.

## Setup

Needs Python 3.10 or newer.

```bash
git clone https://github.com/amuhammadwaseem867-ctrl/quobot- today-trader
cd today-trader
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Use

```bash
# Scan the default watchlist on 5-minute candles
python -m today_trader scan

# Your own assets and timeframe (1m 2m 5m 15m 30m 1h)
python -m today_trader scan EURUSD GBPJPY XAUUSD BTCUSDT -i 1m

# Show the reasons for every asset, not just the ones with a bias
python -m today_trader scan -v

# Re-scan every time a candle closes
python -m today_trader watch EURUSD GBPUSD -i 1m

# Check how the signals would have done on recent history
python -m today_trader backtest EURUSD GBPUSD -i 1m --expiry 1 --payout 0.85

# Try it offline with synthetic data
python -m today_trader scan --demo
```

Asset names: forex pairs as `EURUSD`, gold `XAUUSD`, silver `XAGUSD`, oil `USOIL`, indices `US30`
`US500` `NAS100`, crypto as `BTCUSDT` `ETHUSDT`. Any other Yahoo Finance ticker also works.

### Telegram alerts (optional)

1. Create a bot with [@BotFather](https://t.me/BotFather) and copy its token.
2. Send your bot a message, then open `https://api.telegram.org/bot<TOKEN>/getUpdates` to find your chat id.
3. Set them before running `watch`:

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...
export TELEGRAM_CHAT_ID=987654321
python -m today_trader watch EURUSD XAUUSD -i 1m
```

You get a message whenever an asset's bias changes to CALL or PUT.

## How the score works

Each candle gets a score from -100 (strongly down) to +100 (strongly up). Indicators vote:

| Group | Indicators | Counts more when |
|---|---|---|
| Trend | EMA 9/21 cross, price vs EMA 50, +DI/-DI | ADX > 25 (trending) |
| Momentum | MACD histogram and its slope | always |
| Reversal | RSI 30/70, Bollinger bands, Stochastic 20/80 | ADX < 25 (ranging) |

A score of +40 or more shows **CALL (up)**, -40 or less shows **PUT (down)**, anything in between
shows **WAIT**. Change the cut-off with `-t`, e.g. `-t 60` for fewer, stronger signals.

## Read the backtest before you trust a signal

With an 85% payout you need to win more than about 54% of trades just to break even. The backtest
prints that break-even line next to the real win rate. Short timeframes (1m) are close to random,
so expect win rates near 50%. If the signals don't beat break-even on an asset and timeframe, don't
trade them there.
